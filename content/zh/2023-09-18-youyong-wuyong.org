重拾博客。还是使用 orgmode 的 publish 功能，直接导出 html 文件，放在 http 服务器上，非常简单的工作流，但仍围绕 emacs 中的 orgmode 展开。没有 orgmode 提供的相关功能，这个流程就没法进行。

为什么要用 emacs 的 orgmode 呢？今天想到这个问题。细思起来，其实我所用的 orgmode 功能，仅仅是作为简单的文本编辑，作些简单的记录，没有用到任何一个高级功能。让我用那些功能，也不会，至今没通览过一遍手册， emacs 也用不溜，有时候连基本的编辑快捷键，如复制、粘贴都会百度一下。

如此的一个“新手”，用了十多年没学会一点高级用法的非主流用户，一个工作与专业与计算机无甚相关的人，竟然会对这么一个需要有一定计算机专业知识的软件念念不忘，断续使用十多年。然后，居然没有一点进步。回过头来，我自己也感觉匪夷所思。

orgmode 于我而言，基本上可以定义为无用的。那么是什么吸引了我，居然想到使用它。可能，思来想去，有这么两点：

1. orgmode 主页上的小标题： *Your life in plain text* ，我觉得可以译作“简单生活”，我对此很受用，尽管使用它并不简单。
2. 纯粹与 emacs 一起，装逼用的。

因为回想起来，最开始使用静态博客时，是用 markdown 标记语言也码字的。后来不知道从哪里看到了 orgmode 似乎功能更强大，就这样无脑入坑了。

最终的结果也无所谓好坏。因为平时生活工作都用不到，所以使用它也没什么进度，唯一的折腾是发现可以用 emacs 加 orgmode 来导出 html，作为一个类似于静态博客工具一样使用的时候，从百度、 google 搜索了不少教程、文章来学习怎么用得更好。其它的，基本没了，从我记录生活的节奏也可以看出，只是偶尔有些心血来潮时记一记，码些字，然后又会很长时间默然无语了。

但是，就这么个近乎无用的东西，在很多时候，却给了我极大的满足感，特别是折腾博客的时候。为什么？因为兴趣，因为创造。虽然通过 orgmode 所建构的这个博客非常简陋，甚至很多博客基本的功能都没有，我也没能力去完善。但这个过程中，我享受到了以兴趣为始，到创造一个“新”事物的过程。因为有这个过程，能满足人心中的某种本能，所以才不停使用至今。

人生，偶尔需要点这样的无用。
