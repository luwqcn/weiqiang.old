Footnotes

），必须单独挑出来。 两条正则分别对应「标题带属性」和「光秃秃的

」两种情况，因为 RE2 没有 反向引用，只能拆开写。已经打过标记（正文里出现过 no-number）就跳过， 免得重复加 class。 注意：这里只匹配纯粹的 h2~h6 开标签；如果哪天给标题加了别的 class， 第一条会再加一个 class 属性（HTML 只认第一个），所以「已处理就跳过」 这道保险不能去掉。 返回值过了 safeHTML：replaceRE 出来的是普通字符串，直接打印会被转义。 */ -}} {{- $c := . -}} {{- if not (in $c "no-number") -}} {{- $c = replaceRE `(?i)]*)>(\s*)(Footnotes?|脚注|注释|参考文献)` `$3$4` $c -}} {{- $c = replaceRE `(?i)(\s*)(Footnotes?|脚注|注释|参考文献)` `$2$3` $c -}} {{- end -}} {{- return ($c | safeHTML) -}}
