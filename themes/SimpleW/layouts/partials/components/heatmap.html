{{- /* components/heatmap.html — one year drawn as a "day grid" (calendar heatmap). Columns are weeks, rows are weekdays, so every day of the year owns exactly one cell. The empty grid is painted once with an SVG ; days that actually have posts are drawn on top at one of N intensity levels. Geometry follows the reference design: 11px cell, 13px pitch, 2px corner radius, 7 rows → the box is always 89px tall and 52 or 53 columns wide. Call with a dict: {{ partial "components/heatmap.html" (dict "year" "2026" "pages" $pagesOfThatYear "cfg" $calendarCfg) }} Reads from `$cfg` (i.e. `[params.listing.calendar]`): weekStart "monday" monday | sunday — which row is the top row levels [1,2,4,7] minimum posts for level 1..N months {} axis labels; empty → i18n `monthShort` maxTitles 12 titles listed in a cell's tooltip before "…" The palette lives in CSS: the cell classes `heat-empty` / `heat-l1..lN` are painted by listing.css, so switching ramps is a pure stylesheet change. */ -}} {{- $year := .year -}} {{- $pages := .pages -}} {{- $cfg := .cfg | default dict -}} {{- $cell := 11 -}} {{- $pitch := 13 -}} {{- $rx := 2 -}} {{- $weekStart := $cfg.weekStart | default "monday" -}} {{- $mondayFirst := eq $weekStart "monday" -}} {{- $levels := slice 1 2 4 7 -}} {{- with $cfg.levels }}{{ $levels = . }}{{ end -}} {{- $maxTitles := 12 -}} {{- if isset $cfg "maxtitles" }}{{ $maxTitles = int $cfg.maxTitles }}{{ end -}} {{- /* Parse as UTC midnight so the day arithmetic is exact everywhere. (A local-time parse would break by one day across a DST boundary.) */ -}} {{- $jan1 := time.AsTime (printf "%s-01-01T00:00:00Z" $year) -}} {{- $dec31 := time.AsTime (printf "%s-12-31T00:00:00Z" $year) -}} {{- $days := add (div (sub $dec31.Unix $jan1.Unix) 86400) 1 -}} {{- /* Row that 1 January lands on: 0 = first row of the grid */ -}} {{- $firstRow := int $jan1.Weekday -}} {{- if $mondayFirst }}{{ $firstRow = mod (add $firstRow 6) 7 }}{{ end -}} {{- /* 52 or 53 columns, and the resulting viewBox */ -}} {{- $cols := div (add (add $days $firstRow) 6) 7 -}} {{- $vw := sub (mul $cols $pitch) 2 -}} {{- $vh := sub (mul 7 $pitch) 2 -}} {{- $patternID := printf "heat-%s" $year -}} {{- $unit := i18n "postsUnit" | default "篇" -}}
